# Raspberry Pi Pico 2 — Data Live Dashboard USB CDC 测试固件

本固件通过 **Pico 2 板载 USB 接口**与电脑通信，不使用 GP0/GP1 UART 引脚，也不需要 USB-UART 转换器。连接电脑后，系统会枚举出一个 USB CDC 虚拟串口，网页通过 Web Serial API 与它收发二进制协议帧。

固件以 100 ms 周期发送模拟转速、油门、速度和功率数据，并响应网页的参数读取/写入请求。参数只保存在 RAM，重启后恢复默认值。它是网页测试设备，不是实际电机/车辆控制程序。

## 1. 编译

安装 Raspberry Pi Pico SDK，并设置环境变量 `PICO_SDK_PATH` 指向本机的 `pico-sdk` 目录。在 `pico2_test_firmware` 目录运行：

```bash
cmake -S . -B build -DPICO_BOARD=pico2
cmake --build build
```

将 `build/pico2_dashboard_test.uf2` 拷贝到处于 BOOTSEL 模式的 Pico 2。烧录完成后，Pico 2 会重启并通过 USB CDC 枚举虚拟串口。

## 2. 网页连接

1. 用 USB 数据线把 Pico 2 直接连接电脑。确保使用支持数据传输的线，而不是仅供电线。
2. 使用桌面版 Chrome 或 Edge 打开网页。建议在网页目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。
3. 进入“遥测界面”，点击“连接设备”，在系统弹窗中选择 Pico 2 对应的 USB 串口设备。
4. 网页的 Web Serial API 要求提供 `baudRate` 参数，因此界面仍显示 19200；但对 USB CDC 而言，它不是实际 USB 传输波特率，不需要和硬件设置匹配。

## 3. 功能测试

1. 检查转速、油门、功率、速度是否持续变化，速度曲线是否持续绘制。
2. 点击“开始记录”，等待 10–20 秒后停止记录；检查用时、距离、能耗、平均功率等统计数据。
3. 点击“导出 CSV”，确认 CSV 文件下载成功。
4. 进入“参数设置”，点击“读取参数”，8 个输入框应收到默认参数。修改参数后点击“写入参数”，设备会回显更新值（仅保存在 RAM）。
5. 进入“数据分析”，加载导出的 CSV，调整三张图的列选择，并测试滚轮缩放、拖动框选缩放、双击复位是否同步。
6. 断开后重新连接，确认连接状态和遥测数据恢复正常。

## 4. 协议

帧格式：`F1 | type | length | ASCII payload | checksum | F6`。校验和是 payload 所有字节累加后取低 8 位。

- 遥测：`0x41` 转速，`0x44` 油门，`0x42` 速度，`0x4A` 功率。
- 参数：`0x51` 至 `0x58`，依次对应网页的 8 个参数。
- 读取参数请求：`F1 60 00 00 F6`；固件依次发送 8 个参数帧。
- 参数写入：接收参数帧后更新 RAM，并回发该参数帧。

CSV 导入/导出、页面切换和图表交互属于浏览器端功能，需要在网页里操作；固件负责提供模拟实时数据和响应参数协议。

## 5. 注意事项

- 必须使用 USB 数据线。
- Pico 2 直接连接电脑即可，不需要接 GP0、GP1 或额外 USB-UART 模块。
- 固件通过 USB CDC 传输二进制数据，因此不要在同一接口输出 `printf` 调试文本，否则会干扰网页协议解析。
- 尚需在本地 Pico SDK 环境编译并在实体板上验证。
