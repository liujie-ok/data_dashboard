# 网页前端说明

本目录是 Data Live Dashboard 网页工程。完整工程和 Pico 2 固件说明见上级目录的 `项目说明_中文.md`。

## 文件职责

- `index.html`：页面结构、三个选项卡、遥测指标、图表画布、按钮和参数输入框。脚本依赖应按文件尾部的顺序加载。
- `style.css`：全局颜色变量、固定高度控制栏、单屏布局、三行分析图布局和小屏样式。修改控制栏高度时只改 `--controls-panel-height`。
- `app.js`：页面主控制器，负责界面事件、实时遥测、图表、数据记录、距离与能量统计、参数操作，以及 CSV 导入/导出。
- `serial-manager.js`：封装 Web Serial API 的端口生命周期、读取循环和串行写入队列。
- `protocol.js`：处理二进制帧编码/解析、校验和、参数发送和数字文本解析。
- `csv-utils.js`：解析 CSV 字段和将数据转换为有限数字。

## CSV 时间格式

导出 CSV 第一列为 `time_mm_ss_cs`，格式为 `MM:SS.cc`（分:秒.百分秒），例如 `00:00.00`、`00:12.34`、`01:05.37`。采样间隔目前是 250 ms，因此虽然格式保留两位百分秒，实际点间隔通常为 0.25 秒。

CSV 默认文件名为 `日志_YYYYMMDD_HHMMSS_NNN.csv`。支持系统保存窗口的浏览器会允许用户选择保存位置和更改文件名。

## 本地打开

在本目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。串口通信建议使用桌面版 Chrome 或 Edge。

## 赛道显示界面

- 导航栏“参数设置”右侧的路线图标进入赛道界面。
- 点击“加载赛道数据文件”选择 CSV 或 GPX 文件；CSV 表头需包含 `latitude`/`longitude`、`lat`/`lon` 或中文“纬度”/“经度”。可选高度列包括 `altitude`、`elevation`、`height`、“海拔”或“高度”。
- 工程附带 `sample_track.csv`，其坐标范围与 Pico 2 USB CDC 测试固件的模拟位置一致，可用于功能演示。
- 赛道路线绘制在上方大窗口中；设备位置由串口经纬度数据叠加显示，“（位置标记由新收到的 GPS 数据自动刷新）”可按最新数据重新绘图。
- 下方较矮的曲线图可切换显示高度、转速、油门、功率或速度，数据采样周期约 250 ms。
- 可导入 GPX 的 `trkpt`、`rtept` 和 `wpt` 节点。此处是基于经纬度的赛道示意图，不含在线地图瓦片。

### 赛道页串口扩展帧

| 帧类型 | 含义 | 单位/格式 |
|---|---|---|
| `0x45` | 设备高度 | 米，ASCII 数字 |
| `0x46` | 纬度 | 十进制度，范围 -90 至 90 |
| `0x47` | 经度 | 十进制度，范围 -180 至 180 |

高度和经纬度帧使用现有二进制封装：`F1 | 类型 | 长度 | ASCII 载荷 | 载荷校验和 | F6`。实际硬件若使用其他类型编号，请同步调整 `app.js` 的 `handleFrame()` 映射与设备端发送协议。GPS 坐标必须与加载的赛道文件采用相同坐标系和区域，否则设备标记会提示位于赛道范围外。


## 最新修改：赛道页记录与导出按钮

- 赛道页已移除“刷新设备位置”按钮。加载赛道后，设备位置标记由串口新收到的经纬度数据自动更新。
- 赛道页串口操作区现在包含“连接设备”“断开连接”“开始记录/停止记录”和“导出 CSV”，与遥测页共用同一串口连接和记录会话。
- 串口连接成功后，两页的开始/停止记录和导出按钮同步启用；未连接或连接断开时均禁用，业务处理函数也会再次检查连接状态。
- 在任一页面开始或停止记录，另一页面的按钮文字和样式会同步；两个页面的 CSV 导出按钮导出同一条记录。


## 赛道绘制比例

赛道路线会等比例缩放，目标占赛道画布高度的 90%，并居中显示。过宽的赛道会优先完整适配画布宽度，避免裁切。
